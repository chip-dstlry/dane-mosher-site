# Performance Specialty Medicine — website

Website for Dr. Dane Mosher, DO (Performance Specialty Medicine, Coeur d'Alene, Idaho).

## What's in here

- `index.html` — the entire site (all styling and animation included)
- `assets/dane-2.jpg` — Dr. Mosher's photo

No build step, no database, no server code — these are plain static files.

## How to host it

Upload both `index.html` and the `assets` folder (keeping them side by side) to any web host:

- **Cloudflare Pages / Netlify (free):** drag and drop this folder in their dashboard, then connect your domain.
- **Any shared host (Hostinger, Namecheap, etc.):** upload the files to the site's root folder (often `public_html`) via their file manager.

To preview locally, just double-click `index.html`.

Fonts and animation libraries load from public CDNs (Google Fonts, jsDelivr), so an internet connection is needed for the full effect — nothing else to install.
