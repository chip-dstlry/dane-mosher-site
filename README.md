# Performance Specialty Medicine — site concept

A design-forward website concept for Dr. Dane Mosher, DO (Performance Specialty Medicine, Coeur d'Alene, Idaho).

Static site — no build step. `index.html` + `assets/dane.jpg`.

- Three.js ambient "cellular field" particle hero
- GSAP + ScrollTrigger reveals, Lenis smooth scrolling
- Bricolage Grotesque / Instrument Sans / Spline Sans Mono via Google Fonts
- Content sourced from performancespecialtymed.com

Deployed via GitHub Pages.
